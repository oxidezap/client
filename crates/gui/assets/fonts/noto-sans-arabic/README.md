The web frontend registers this fallback before its first frame. IBM Plex Sans
and Lilex do not cover Persian. This adds Arabic-script glyphs without changing
the primary UI family or requiring a separate network request. The font is
240,456 bytes uncompressed. Desktop builds continue using system fonts.
